### 🏗️ System Design Fundamentals

- **API-first design** — schema → contract → implementation
- **Separation of concerns** — controllers / services / repositories
- **Layered, class-based services** — thin controllers + constructor-injected, unit-testable services
- **Role-based access control (RBAC)** — multi-role systems for teams
- **Stateless backend design** — JWT + refresh token rotation, ready for horizontal scaling
- **Optimized DB schemas** — MongoDB indexing, projection, and relationship modeling
- **Relational modeling** — PostgreSQL schemas with full referential integrity
- **Scalable state management** — Zustand slices with optimistic UI + server reconciliation
- **Containerization** — Docker / Docker Compose, orchestration with Docker Swarm

### 🎥 EduVision — Video-Course Platform for Security Systems Training
> Backend for a video-course platform teaching smart security systems (IP cameras, video doorbells, alarm systems, NVR/DVR).

**Stack:** Node.js · TypeScript · Express 5 · Drizzle ORM · PostgreSQL 17 · JWT · Docker / Docker Compose
**Timeline:** 2025

- 🎓 Course browsing, per-course payment via **Vodafone Cash** (receipt upload + admin approval), sequential lesson unlocking via quizzes, and certificate issuance on completion
- 🏗️ Layered, class-based service architecture — one service per domain (Auth, User, Course, Lesson, Quiz, Enrollment, Payment, Certificate) with thin controllers and constructor-injected, unit-testable services
- 🗄️ 10-table relational schema with Drizzle ORM / PostgreSQL (users, courses, lessons, quizzes, questions, options, quiz attempts, enrollments, payments, certificates) with full referential integrity
- 🐳 Containerized API + PostgreSQL with Docker & Docker Compose, hot-reload dev tooling (tsc-watch) and migration workflow via Drizzle Kit
- 🔐 JWT auth with RBAC (admin / instructor / student) and centralized error-handling middleware
